# 这波整了啥

## T1: 试试任务三态

**这是啥**: 左栏「计划」面板里，每个任务右边有两个圆钮：叉=要改，勾=放行（都可撤回）。

**因为啥**: 「没看」和「看过了但不行」必须分开——沉默不等于通过。

**会咋坏**: 两个钮挨得近，可能点错。

**咋修复**: 再点一次同一个钮就回到待审。

**变更**:
- 文件: examples/demo.md
- 类型: docs

**验收**:
- [ ] 把 T1 标成「放行」，正文标题会变删除线
- [ ] 再点一次，撤销恢复

**证据**:
- 命令: 打开审阅页点一下试试
- 结果: 正文同步变化
- 状态: verified

## T2: 试试批注

**这是啥**: 正文里选中一句话 → 弹出小工具条 → 写评论或标删除。

**因为啥**: 批注要能定位到具体句子，AI 才知道改哪儿。

**会咋坏**: 选不中多半是浏览器扩展在抢选区。

**咋修复**: 换一个干净的浏览器窗口再试。

**变更**:
- 文件: examples/demo.md
- 类型: docs

**验收**:
- [ ] 随便批一条，右栏出现卡片

**证据**:
- 命令: 选中上面任意一句话
- 结果: 工具条出现
- 状态: verified
