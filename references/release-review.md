# 摘要
标签文案按你指定的原话和标点更新，主题、布局和小墨设计保持原样。

## T1: 新标签
- ❓ 啥玩意儿？
- 🗺️ 先说个大概（本次未改）
- 🔍 真滴假滴？
- 🔬 举个例子呢...
- 🔄 不行咱换招儿试试呢？
- 📉 别整出新毛病...
- 🚫 跑偏了嗷！
- 🧪 测试一下子呗...
- 👍 没毛病嗷！

工具条的单独 👍 按钮改为“还行嗷！”。已移除“沿用现有做法”默认标签。旧默认标签设置自动更新，自定义标签和历史批注保留。

**这是啥**：只修改标签文字和默认标签列表。

**因为啥**：采用你指定的东北话口吻。

**会咋坏**：旧设置可能继续显示旧词，历史批注可能失去标签识别。

**咋修复**：按稳定编号识别旧内置文案并迁移，兼容旧英文、旧中文与新文案，自定义内容保留。

**验收**：
- [ ] 打开设置里的快捷标签，检查原话和顺序。
- [ ] 选中内容，点 👍，试试“还行嗷！”。

**证据**：5 项标签回归通过；UI 类型检查及生产构建通过；便携包四端与 V2 插件夹具检查通过。未推送 GitHub。
